# 데이터셋 관리

최종 갱신: 2026-11-06. 현재 앱0.8.0 / 인식 규칙 r1 / 임의 평가 참조셋0.2.

| 종류 | 목적 | 관리 문서 |
|---|---|---|
| 인식용 | 어떤 동작을 시작했고 언제 끝났는가? | [인식용 데이터와 판별 조건](recognition-ko.md) |
| 평가용 | 그 동작의 조작이 비교 기준 안에 있는가? 얼마나 감점하는가? | [평가용 데이터와 채점 기준](evaluation-ko.md) |

[변경 이력](../CHANGELOG-ko.md)에 수치·출처·버전·검증을 함께 기록한다. 코드/JSON을 수정하는 작업에서 이 문서들도 함께 갱신한다. 프로젝트 루트 AGENTS.md에 유지 규칙을 남겼다. 예약 실행이나 자동 데이터 수집은 설정하지 않았다.

현재 인식은 규칙 기반이며 학습한 ML 모델이 없다. 평가 수치는 임의 시제품 기준이고 전문가 검증이 필요하다. **인식 문턱과 평가 문턱을 혼용하지 않는다.** 예를 들어 감속0.3m/s²는 정지 관측을 시작하는 조건이며 급감속 비교 기준3.5m/s²와 다르다.

확보/미확보 자료는 [사용 매핑](../../dataset-implementation-v8-ko.md), 실행한 검사 원본은 [검증 기록](../../verification-v8-ko.md)에 연결한다.

공개 자료를 읽는 법과 주요 용어는 [자료별 README·공식 소개 풀이](../readme-interpretation-ko.md)에 정리했다.
