# 코칭 시작 한 번으로 전체 주행 관측

변경일 2026-11-06. 사용자의 최신 요청에 따라 에뮬레이터를 실행하지 않고 구조를 수정했다.

## 실행 경로

`HomeScreen → EasyCarViewModel.startCoaching → CoachingService → DriveRuntime → CoachEngine → PolicyScorer → ImmediateFeedback`

홈의 유일한 코칭 시작 버튼은 모든 동작 감지를 활성화한다. 설정의 입력 선택은 차량/합성 공급원만 정한다. 서비스에는 parking/focus/useReference 인자를 보내지 않는다. `PracticeContext.parkingType`, `focusType`, 저장 기록의 focusType은 예전 JSON을 읽기 위한 호환 필드이며 인식·발화 필터에 사용하지 않는다.

코어는 원래 입력 시각으로 진행한다. `accept(frame)`이 종료 조건을 충족한 현재 프레임에서 결과를 반환한다. 런타임은 그 결과를 먼저 카드·음성 큐에 게시하고 체크포인트로 저장한 뒤 선택 영상 분석을 수행한다. 영상·TTS 준비에 화면 피드백을 종속시키지 않는다. 음성은 실제 onStart/onDone과 포커스 상태를 별도로 기록한다. 무음·실패·대기·세션 종료는 발화 완료로 기록하지 않는다.

## 동작 경계와 자동 선택

| 동작 | 후보와 종료 조건 |
|---|---|
| 출발 | 정차 유지 뒤 D 실제 이동. 최소 관측 후 가속이 끝나거나 출발 관측 창 4초 경과 |
| 정지 | 충분한 속도로 무장된 상태의 감속 뒤 정차 1.2초 유지 |
| 좌·우회전 | D 이동 중 조향 시작. 핸들 복원·진행 방향 안정 후 종료. 신뢰 가능한 누적 방향 변화 55~120도와 조향 부호 일치로 분류 |
| 유턴 | 같은 회전 종료 조건, 방향 변화 150~210도 |
| 주차 후보 | 저속 안정 R 또는 확인된 대상 공간 안의 저속 D 이동. 후보 안의 출발·정지·조향은 하위 단계로 묶음 |
| T자/평행 구분 | 대상 공간과 차량의 연관이 검증된 도로축·주차칸축. 축 차이 90±15도는 T자, 0±15도는 평행. 그 외/누락/변경/오래된 공간은 유형 미확인 |
| 주차 종료 | P+정차 1.2초 유지. 유형 판정에 마지막 공간 관측 1.5초 이내 필요. P만으로 주차 성공을 뜻하지 않음 |

모든 감지 임계값은 시제품 파라미터다. 모범운전 허용 범위가 아니다. 주차 뒤 D 이동·공간 이탈이 1초 이상 확인되어야 다음 후보를 시작해 중복을 막는다. 무리한 속도 이탈/5분 초과/필수 신호 공백/세션 종료는 완료로 꾸미지 않고 중단 근거를 남긴다. 실제 기어 0.5초 안정, N 경유·콜백 중복·짧은 흔들림을 처리하며 속도 부호로 기어를 생성하지 않는다.

인식은 규칙 기반 시제품이며 도로 곡선과 교차로, 헤어핀과 유턴을 실차에서 완전히 구별한다고 주장하지 않는다. 주행·운전자별 독립 데이터셋 검증과 도로/주변 맥락 공급이 후속 과제다. 현재 Pleos heading 신뢰도 및 주차 공간 공급원 부재 때문에 실제 입력에서는 미확정 결과가 많을 수 있다.

## 평가 정책

활성 프로필 `auto-coach-draft-0.3`, 정책 `evaluation-design-0.1`. 상태는 `DRAFT_REQUIRES_EXPERT_VALIDATION`이고 `real_world_scoring_enabled=false`다. 프로필의 기존 수치 필드는 이전 JSON 스키마 호환을 위해 남겨 두었으나 신 정책의 실제 허용 범위로 사용하지 않는다. 구버전 합성 채점기는 과거 회귀 시험을 위한 경로다. 앱 새 세션에는 정책 객체를 명시적으로 전달한다.

- 전문가 검증·차종/공간 일치·항목별 승인된 B/S/tau가 모두 있어야 연속 지표 감점 가능. 현재 배포 자산에는 승인된 항목이 없다.
- 속도/실제 기어 유효 신호 95% 및 진입/종료 핵심 0.5초 구간을 확인한다. 조향 미분은 측정 시각을 요구한다. 미확인 필수 항목이 하나라도 있으면 총점을 보류한다.
- 연속 이탈은 0.3초 이상 이어진 구간의 정규화 초과량을 적분한다. `round_half_up(cap * min(1,E/tau))`. tau는 고정 승인 노출시간이며 동작 전체 길이로 나누지 않는다.
- 가속/감속/jerk의 같은 원인은 그룹 안에서 최댓값만 취한다. 속도 진입/회전/탈출은 표본을 중복 배정하지 않고 총40점으로 제한한다. 조향/탈출 복원도 최댓값을 취한다. 상세 항목의 적용 점수 합이 실제 감점 합과 일치한다.
- 원인 불명 감속이 감점 후보이면 연계 가감속/jerk의 감점과 총점을 보류하고 측정값은 보존한다. 운전자 과실이나 차체 충격으로 단정하지 않는다.
- 정적 자세 오차는 별도 정규화한다. 침범은 검증된 이진 관측일 때만 해당 예산을 적용한다. 보정·시간·최종 P/정차 근거가 없으면 보류한다.
- 확정된 주차의 R→D 배점만 기존 시제품 공식을 유지한다. 실제 기어가 없으면 횟수 측정값도 null이며 0회로 표시하지 않는다. 공간 근거가 없어 주차로 확정되지 않으면 관측 N은 남겨도 배점은 적용하지 않는다.
- 참고값은 참고값으로만 표시한다. nuPlan 종방향 jerk 4.13과 벡터 크기8.37을 구분한다. 모델 학습·전문가 기준 확정·서명된 실차 프로필 활성화는 수행하지 않았다.

## 검증용 입력

`auto-drive`는 출발 6.8초, 좌회전17.9초, 우회전30.9초, 유턴45.8초, 정지56.1초, T자주차90.9초, 평행주차110.4초에서 결과를 내는 합성 입력이다. 전체 종료111.1초 이전에 모두 게시한다. T자/평행의 R→D는 각각3회/1회이며 임시 배점12/2점, 총점은 모두 null이다.

신호 JSON에는 동작 정답·선택 타입이 없다. 공간 관측에는 축·연관·품질·출처만 들어간다. 정답 파일은 런타임에서 읽지 않는다. 미지 공간·사선·낮은 품질·오래된 공간·대상 변경·전진 주차·다중 주차·중단 역주행 회귀 시험을 포함한다. 실제 외부 데이터 성능이나 발화 지연을 이 합성 결과로 대신하지 않는다.
