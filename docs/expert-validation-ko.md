# 전문가 기준 검증 계획

현재 기준은 **시제품용 합성 예시**입니다. 다음 자료를 확보하기 전 실차 점수를 활성화하지 않습니다.

1. 차종·연식·타이어·적재·핸들 부호·신호 단위·측정 지연을 고정하고 센서 시간축을 검증합니다. 시험 장소는 평탄한 폐쇄 코스로 한정하고 회전 반경·도로 폭·주차칸 치수·경사를 실측합니다.
2. 훈련된 운전 강사 여러 명이 같은 코스에서 여러 적절한 조작을 반복합니다. 한 사람의 궤적을 단일 정답으로 만들지 않습니다. 위험 조작을 의도적으로 유발하지 않고 악조건 검증은 시뮬레이션을 우선합니다.
3. 원시 신호·승인된 탑뷰·동기화 이벤트를 동의하에 수집하고 가명 처리합니다. 측정 시각과 수신 시각을 별도로 남기며 누락·필터·구간 라벨 출처를 유지합니다. 보관·삭제·접근 권한을 정합니다.
4. 최소 두 평가자가 라벨과 점수를 독립적으로 매기고 일치도·불일치 사유를 확인합니다. R→D 횟수는 안정 기어 수동 라벨과 비교합니다. 영상 각도·침범은 실측 위치와 비교합니다.
5. 차종·코스·공간별 허용 범위는 중앙값/분위수와 전문가 허용 판단을 함께 사용합니다. 주차 진입각 하나를 모든 장소에 적용하지 않습니다. 곡선·차로 변경·S자·단순 후진을 별도 음성 샘플로 구성합니다.
6. 운전자·차량·촬영 날짜 기준으로 학습/보정/검증 집합을 분리합니다. 정확도·재현율·오탐·미확정 비율, 신호 누락에서의 보류 비율, 각도 오차·침범 오탐, 조건별 편향을 보고합니다.
7. 가중치·연속 이탈시간·감점 상한은 운전 강사의 등급·설명과 비교해 보정합니다. 큰 이탈·긴 이탈에서 감점이 감소하지 않는지, 중복 감점과 동작 길이 편향을 재검증합니다. R→D 항목은 첫 전환부터 가중 감점하는 제품 요구를 유지하며 임시 수치는 교체 가능합니다.
8. CarUxRestrictions 변화, 내비·통화·안전 경고 우선순위, 앱 전환, 프로세스 종료, 재연결, 배터리/CPU/메모리를 OEM 시험환경에서 검증합니다. 차량 제조사/플랫폼 심사와 사용자 접근 권한을 확보한 뒤 대상 버전·차종별로 출시 범위를 제한합니다.

검증을 통과하면 ReferenceProfile 버전을 새로 발행하고 출처·검증 표본·오차·적용 조건을 문서화합니다. 과거 기록의 원래 프로필 버전을 바꾸지 않고, 개인 점수에 맞춰 기준을 낮추지 않습니다. 학습 지표를 사고 예측이나 운전 적격 판정으로 확대하려면 별도의 연구·검증이 필요합니다.
