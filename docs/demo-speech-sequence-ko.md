# 데모 음성 완료 후 다음 동작 · 0.9.2

변경일: 2026-11-07. versionCode11 / versionName0.9.2.

0.9.1은 데모 신호를 계속 재생했다. 음성이 길거나 배속이 빠르면 다음 회전/후진에 진입했고, 기존 발화 제한이 앞선 안내를 중단했다. 마지막 음성도 세션 종료 대기20초를 넘기면 중단될 수 있었다.

0.9.2는 완료 피드백이 생기고 정차/직진으로 안내 가능한 프레임에 도달하면 데모 입력을 멈춘다. 음성 준비·설정된 최소 안내 간격·실제 발화 완료 콜백을 기다린 뒤 다음 프레임을 재생한다. 마지막 안내도 동일하게 기다린 뒤 요약을 연다. 화면 카드의5초 수명과 음성 재생 완료는 별개다.

데모 대기 음성에는 기존18초 만료를 적용하지 않는다. 최소 안내 간격30초를 선택해도 안내를 건너뛰지 않는다. 무음은 기다리지 않는다. 엔진이 명시적으로 실패하거나 초기화 응답이12초 동안 없으면 실패 상태를 기록하고 화면 안내로 진행한다. 통화/우선 오디오와 사용자가 직접 누르는 일시 정지·종료는 계속 음성을 중단할 수 있다. 합성 입력으로 만든 우선 오디오 시험 구간은 다음 프레임으로 지나가 제한이 해제되게 한다.

실제 차량 관측은 음성 때문에 입력 수집을 멈추지 않는다. 인식/평가 기준, 점수, 프로필, 원본 데모 시각/프레임, 과거 기록을 변경하지 않았다.

구현: [데모 재생 대기](../app/src/main/java/com/example/easycar/runtime/DriveRuntime.kt), [음성 대기/완료 상태](../core/src/main/kotlin/com/easycar/core/ImmediateFeedback.kt).
