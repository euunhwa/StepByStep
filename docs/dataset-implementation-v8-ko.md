# 데이터셋과 실제 사용 구현 · EasyCar 0.8.0

확인일 2026-11-06. 공개 데이터 조사, 실제 보유 파일, 임의 생성 자료, 학습된 모델을 구분한다. 현재 인식 엔진은 규칙 기반이며 **학습한 머신러닝 모델은 없다.**

상시 관리 문서는 [인식용](datasets/recognition-ko.md)·[평가용](datasets/evaluation-ko.md)·[변경 이력](datasets/CHANGELOG-ko.md)입니다. 현재 참조셋0.2/프로필0.3, 정책0.4이며 최신12개 비교값은 평가용 문서를 따릅니다.

정확한 파일 크기·SHA-256·입력 출처는 `validation/dataset-inventory-v8.json`에 기록한다. 생성 코드 `tools/generate_provisional_reference.py`를 다시 실행하면 동일 평가 참조셋을 생성한다. 생성 과정에 인터넷 다운로드·공개 데이터 적합·전문가 라벨을 사용하지 않는다.

## 임의 평가셋이 점수에 들어가는 경로

1. `assets/evaluation/arbitrary-reference-v1.json`: arbitrary=true, expert_validated=false, requires_improvement=true, 앱 공지,7종 참조 범위,12개 임시 비교 지표.
2. `arbitrary-reference-episodes-v1.json`: 합성 참조 구간의 속도/기어/핸들/방향 시계열926개. 정답 점수·운전 강사 등급이 없으며 학습 모델을 만들지 않았다.
3. `evaluation-policy-prototype.json`: 평가 참조셋 ID와 사용자 허용 임시 점수 모드, 출발100/정지100/회전40·30·30/주차30·30·10·20·10 배점.
4. `EvaluationPolicy.fromJson(policy,dataset)`: 원본 임의 생성 표기·개선 필요 공지·일곱 유형·수치 범위·ID 일치를 검증한다. 이 파일이 없거나 전문가 검증 자료로 잘못 바뀌면 임의 점수를 활성화하지 않는다.
5. `PolicyScorer`: 임시 비교에서는 이 참조셋의 B/S/tau를 사용한다. ScoreKind=PROVISIONAL, scoreBasis=공지, 프로필/정책 버전을 결과와 피드백에 저장한다.
6. 실시간 화면은 N점과 짧은 원인을 표시하고 기록은 임시 점수와 버전을 보존한다. 홈·설정·상세·미니 창에 **평가용 데이터셋은 임의로 만든 자료이며 개선이 필요합니다**를 남긴다.

**926개 원시 시계열을 학습하거나 실시간 궤적 매칭에 사용하지 않는다.** 시계열은 합성 참조 예제의 재현·검사 자료이며, 런타임 점수는 개발자가 임의로 정한12개 B(비교 경계)/S(초과량 정규화)/tau(노출 시간)와 배점 파일을 읽어 계산한다. 따라서 이 수치들이926개 표본으로 통계 추정됐다고 해석하면 안 된다.

공개 nuPlan 참고값은 별도 참고 열에만 표시한다. 이번 임시 허용값이 nuPlan·Waymo·실제 공개 운전자 점수로 보정됐다고 주장하지 않는다. R→D 수식 min(30,n(n+1)) 역시 제품 시제품 배점이며 전문가 안전 기준이 아니다.

## 실제 신호가 없을 때

임의 평가셋을 만들었다고 미수신 신호를 생성하지 않는다. 속도·기어 품질/공백, 조향 센서 측정 시각, 진행 방향 품질, 대상 주차 공간과 최종 보정 영상이 부족하면 해당 총점을 보류하고 실제 원인을 표시한다. 가감속 점수는 P/N 등 미분을 정의하지 않는 단계와 정상적인 기어 전환 직후의 미분 준비 표본을 구분하고, 그 이후의 누락은 보류한다. v0.8 임의 관측 모드는 제동 상황 원인이 없어도 관측 조작 점수를 제공하며 과실 판정과 구분한다. 필수 신호 부족은 계속 보류한다. 전문가/기존 정책의 원인 보류는 유지한다.

기본 코칭 시작은 항상 차량 서비스 입력이다. 이전 demo_input 설정이 남아도 데모로 바뀌지 않는다. 일반 Android 데모 빌드는 차량 입력 미지원 이유를 표시하고 우측 상단 데모로 안내한다. 과거 합성 기록은 원래 합성 출처를 유지한다.

## 추가로 검토한 평가 자료

- [Waymo E2E](https://www.waymo.jp/intl/jp/open/data/e2e/): 전문 평가자가5초 후보 궤적을0~10으로 평가하는 라벨을 제공한다. 유용한 평가 자료이지만 EasyCar7종 조작/기어/주차 결과와 바로 대응하지 않으며 원자료를 확보·가공하지 않았다. waymo.com 경로는 계정 로그인으로 이동하여 현재 도구에서 접근 불가였다. 향후 궤적 평가 모델 개선 후보.
- [Parking Subjective Evaluation](https://data.mendeley.com/datasets/b3k5566f9c/1), DOI10.17632/b3k5566f9c.1, CC BY4.0: 수동/자동 주차의 평가 지표 우선순위와 참여자 주관 평가 자료. 차량 시계열과 함께 일곱 동작 점수를 주는 모범 자료로 확보한 상태는 아니며 현재 배점에 사용하지 않았다.
- [UAH-DriveSet 원 논문](https://www.robesafe.uah.es/personal/roberto.arroyo/docs/Romera16itsc.pdf): 정상/졸음/공격적 주행을 연기한6명·6차량 자료. 정상은 평소대로 운전하도록 요청한 조건으로, 운전 강사가 수용한 일곱 동작의0~100점 정답을 의미하지 않는다. 현재 원자료 미확보·미학습.
- Honda HDD, INTERACTION, DLP, nuScenes CAN, nuPlan의 확보 범위·라이선스·누락은 이전 [조사 기록](dataset-research-2026-11-06/README-ko.md)과 카탈로그에 보존한다. 목록 조사만 한 자료를 실제 학습 데이터로 세지 않는다.

## 개선해야 할 점

실제 차종/공간의 전문가 수용 사례와 부적절 사례를 수집하고, 여러 평가자가 구간·원인·점수를 독립 평가해야 한다. 운전자/날짜별 독립 검증으로 허용값·정규화·노출시간·배점을 보정하고, 도로 곡선/차로 변경/헤어핀/단순 후진 오인과 보류율을 검증해야 한다. 사용자 점수에 맞추는 방식으로 임의 기준을 조정하지 않는다.
