# EasyCar0.6.0 · 평가 완화와 다음 동작 대기 검증

확인일 2026-11-06 / Asia·Seoul. 실제 프로젝트 `/Users/genius/AndroidStudioProjects/EasyCar`에서 빌드 후 Pleos Connect v2.1.0 한 대에 설치했다. CPU2코어·RAM3GB를 사용했고 Gradle과 에뮬레이터를 동시에 실행하지 않았다.

## 변경 사항

- 임시 가속 B/S/tau:1.8/1.2/1초→3.0/3.0/3초. 감속:2.0/2.0/1초→3.5/3.0/3초. 종방향 jerk:4.0/4.0/1초→6.0/6.0/2초.
- 인식 규칙 r1은 그대로다. 평가 기준을 완화하면서 탐지용 감속0.3m/s²를 바꾸지 않았다.
- 전체/낮은 높이 주행 화면이 마지막 결과를 무기한 읽던 원인을 수정했다. ImmediateFeedback의 표시 가능한 결과만 Runtime 상태에 전달하고 공통 타이머로5초 후 해제한다. 미니도 같은5초 상수를 사용한다.
- 차량 입력 공백이나 데모 일시정지 중에도 표시 만료를 갱신한다. 기록/음성 대기열은 지우지 않으며 늦은 음성/영상 보정은 원래 게시 시각을 바꾸거나 카드를 부활시키지 않는다.
- [인식용 문서](datasets/recognition-ko.md), [평가용 문서](datasets/evaluation-ko.md), [변경 이력](datasets/CHANGELOG-ko.md), 루트 AGENTS.md에 관리 규칙을 추가했다. 새 참조셋/프로필0.2, 정책0.3을 저장하며 과거 기록을 다시 채점하지 않는다.
