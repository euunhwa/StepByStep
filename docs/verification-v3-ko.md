## 근거 파일

- `validation/core-v3-TEST-*.xml`: 코어53개 결과 원본.
- `validation/core-lint-scenarios-v3.log`: 코어·45종 출력·두 flavor Lint.
- `validation/apk-and-instrumentation-compile-v3.log`: 앱/계측 APK 컴파일. 기기 실행 로그가 아님.
- `validation/lint-v3-{demo,pleos}.sarif`: 정적 검사 세부 경고.
- `validation/target-build-v3.log`: 지정 프로젝트의 최종 빌드 로그 (반영 후 생성).
- `validation/apk-sha256-v3.json`: 최종 APK의 SHA-256 (반영 후 생성).

## 현재 한계

차량 모드에서 FusedLocation heading의 시계·confidence 의미와 핸들 측정 시각은 검증 대기다. 도로축/대상 주차 공간 공급원도 없다. 따라서 실제 신호에서 회전/주차 종류를 강제 확정하지 않고, 근거와 보류 이유를 남긴다. 공개 데이터셋 연구 초안만 연결했으며 전문가 기준이나 학습 모델을 확보했다고 주장하지 않는다. 현재 활성 프로필은 DRAFT여서 실제 총점을 부여하지 않는다.
