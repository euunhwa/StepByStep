# 주차 녹화0.13 실험 보관

2026-11-07 사용자 요청으로 앱에서 제외했다. 이 디렉터리는 Gradle 소스/자산 경로가 아니며 APK에 포함되지 않는다. 현재 메뉴는 홈·기록·설정 세 개다.

일반 화면/도로 카메라 녹화와 합성 탑뷰 채점은 시험했지만 실제 위에서 보는 어라운드뷰 영상은 확보하지 못했다. MediaProjection 녹화 서비스·별도 주차 화면·신규 배점·예제·검사 원본을 향후 검토용으로 보관한다. 기존0.13 기록을 읽는 DTO와 PARKING enum만 활성 코드에 남긴다. 과거 점수는 재계산하지 않는다.

현대/Pleos 측에서 승인된 보정 탑뷰 영상/스트림/API와 녹화·저장 권한, 차체 외곽·해상도·시각/보정 정보를 제공하면 재검토한다. 실제 영상으로 네 경계·차체 정합과 신호 동기화를 검증해야 한다. 재도입하더라도 상위 메뉴는 세 개를 유지하고 홈/기록 안에서 기능을 제공한다. GitHub 제출 시 이 전제와 미구현 범위를 루트 README에 계속 명시한다.

원래 실험 설명과 검증은 `docs/parking-capture-ko.md`, `docs/validation/parking-capture-summary-v013.json`에 남아 있다.0.13 합성 배점은 현재 활성 정책이 아니다.
